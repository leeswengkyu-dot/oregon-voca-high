# 보카 트레일 주니어 (뉴오리건영어학원 초등부)

초등학생용 영어단어 탐험 웹앱입니다. 숲 지도 위의 주제별 마을을 다니며 단어를 익히고, 상황 시뮬레이션으로 실제 대화를 연습합니다.

## 기능
- **주제별 단어 120개**: 새싹 숲(1~2학년)·줄기 숲(3~4학년)·나무 숲(5~6학년), 12개 마을 × 10단어
- **학습 모드**: 단어 카드(발음·예문), 짝 맞추기, 스펠링 풍선, 말하기 도전(음성인식), 마을 퀴즈(8/10 이상 배지)
- **상황 시뮬레이션 4종**: 패스트푸드점 주문, 마트 장보기, 병원, 길 찾기
- **보상**: 도토리 포인트, 계급(새싹→다람쥐→사슴→부엉이→숲지기), 배지, 반별 이번 주 열심상 TOP 5
- **선생님 화면**: 학생 현황, 많이 틀린 단어, 반 추가·이름 변경·삭제, 학생 비밀번호 재설정·반 이동

## 구성
- Vite + 순수 JavaScript, 발음은 브라우저 음성(TTS)
- Supabase: 학생·반·학습 기록 저장 (`supabase/schema.sql`). 테이블은 RLS로 잠그고 함수(RPC)로만 접근
- 환경변수가 없으면 이 기기에만 저장하는 체험 모드로 동작

## 배포
1. Supabase 새 프로젝트 → SQL Editor에서 `supabase/schema.sql` 실행
2. Vercel에서 이 저장소 Import → 환경변수 추가
   - `VITE_SUPABASE_URL` = 프로젝트 URL
   - `VITE_SUPABASE_ANON_KEY` = anon public key
3. Deploy

초기 선생님 비밀번호는 `oregon1234` 입니다. 첫 접속 후 선생님 화면 > 설정에서 바꾸세요.
