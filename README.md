# 보카 트레일 주니어 · 뉴오리건 초등 VOCA

초등 1~6학년이 그림·단어·문장 놀이로 배우는 3레벨 웹앱입니다. 기존 학원 로고, 상황 시뮬레이션, 반 관리와 배지를 유지하고 커리큘럼을 확장했습니다.

| 레벨 | 대상 | 단어 | 마을 | 학습 방향 | 퀴즈 |
|---|---|---:|---:|---|---|
| Level 1 새싹 숲 | 초등 1~2학년 | 300 | 15 | 친숙한 명사·그림·쉬운 표현 | 10문항·3지선다·8개 통과 |
| Level 2 줄기 숲 | 초등 3~4학년 | 400 | 20 | 학교·일과·장소·직업·동작·형용사 | 12문항·4지선다·10개 통과 |
| Level 3 나무 숲 | 초등 5~6학년 | 500 | 25 | 동사·형용사·부사·전치사·접속사·문장 구조 | 15문항·4지선다·12개 통과 |

총 1,200개 어휘 항목(뜻이 다른 동형어는 별도), 60개 마을입니다. 각 마을은 20개 단어를 5개씩 나눈 네 번의 카드 학습, 발음 듣기, 짝 맞추기, 스펠링, 문장 블록, 퀴즈를 제공합니다. Level 2·3은 뜻과 문맥을 연결하는 문제를 사용합니다. 개인 공개 순위 대신 도토리·배지·캐릭터 성장과 반 공동 목표를 사용합니다.

## 개발·검증

Node.js 22 이상을 사용합니다.

```sh
npm ci
npm test
npm run build
npm run dev
```

환경변수가 없으면 기기 로컬 체험 모드임을 표시합니다. Vercel Production 빌드는 Supabase 공개 설정이 없으면 중단합니다. `.env.example`을 참고하세요. `service_role` 또는 `sb_secret_` 키가 VITE_ 변수에 들어가면 빌드가 중단됩니다.

- `src/data/level1-source.js`: Level 1의 이중언어 콘텐츠.
- `src/data/curriculum-extra.js`: Level 2·3의 단어와 예문.
- `src/data/words.js`: 1,200개 어휘 정규화와 기존 120개 ID 호환.
- `src/data/levels.js`: 레벨 정의·진도·퀴즈·문장 비교.
- `src/db.js`: Supabase RPC와 로컬 체험 모드.
- `src/excel.js`: 5개 시트 Excel 검증과 변경 미리보기.
- `public/sw.js`: PWA 앱 셸 캐시와 오프라인 실행.
- `docs/DEPLOYMENT.md`: GitHub → Supabase → Vercel 배포 절차.

커리큘럼 수정 후 `npm run seed:generate`로 Supabase 시드를 다시 생성하세요. 신규 제작 예문과 난이도는 영어교육 담당자 검수가 필요한 초안이며, 교육부 지정 목록이나 중학교 공식 교육과정 인증을 의미하지 않습니다.

## 기록과 관리자

학생은 기존 방식대로 반·이름·4자리 PIN으로 입장합니다. 같은 학생의 온라인 기록은 기기 간 공유하며, 새 로그인 시 이전 학생 토큰은 만료됩니다. 토큰은 7일간 유효합니다. 로컬 체험에서는 한 기기에만 기록됩니다.

기존 단어 진도와 배지를 삭제하지 않습니다. 이동한 9개 어휘 ID는 별칭으로 연결하며, 기존 ID와 새 ID에 진도가 함께 있어도 레벨 학습 단어 수는 한 번만 셉니다. 다섯 단어 학습 중 카드 위치는 Supabase에 저장합니다. 결과 저장 요청에는 고유 ID를 사용해 재시도로 도토리가 중복 지급되지 않게 합니다.

**온라인 선생님은 Supabase Auth 개인 계정으로 로그인합니다.** `ojv.teachers`에 등록된 사용자만 학생·반·과제 관리 함수를 실행할 수 있고 `admin` 역할만 Excel 게시를 실행합니다. 공개 초기 비밀번호를 온라인 인증에 사용하지 않습니다. 기존 공용 비밀번호 로그인은 새 버전에서 폐기됩니다. 로컬 체험용 관리자 비밀번호는 해당 기기의 테스트 데이터에만 적용됩니다.

운영 데이터는 공유 Supabase 프로젝트의 `ojv` 스키마에 격리됩니다. 직접 테이블 권한은 모두 거부하며 학생 토큰 또는 Auth 역할을 검증하는 공개 RPC만 사용합니다. 이전 `public.ojv_*` 데이터는 삭제하지 않고 `_legacy` 표로 보관하며 호환 뷰를 통해 전환합니다.

말하기는 보호자 동의 확인 후 선택적으로 사용합니다. 브라우저 제공 음성 인식 서비스로 전달되며, 인식된 표현을 목표 표현과 비교합니다. 발음 정확도 점수를 제공하지 않습니다. 브라우저 제공업체의 데이터 처리 조건과 동의 절차를 실제 운영 전에 확인하세요.

## 검증 범위

자동 테스트는 어휘 수와 레벨별 난이도, 기존 기록 호환, PostgreSQL의 실제 스키마·bcrypt·RLS·관리자 권한·체크포인트·보상 중복 방지, DOM 기반 레벨 전환·학습·저장 재시도·문장 블록을 검증합니다. PostgreSQL 테스트는 PGlite와 실제 pgcrypto 확장을 사용하고, Supabase의 `auth.uid()` 환경만 테스트용 JWT 설정으로 재현합니다.

실제 Supabase 프로젝트 연결, Vercel 배포, 모바일 렌더링·마이크·음성 재생은 별도의 실제 환경 확인이 필요합니다. 소스와 테스트 준비 상태를 실제 서비스 배포 완료와 혼동하지 마세요.
