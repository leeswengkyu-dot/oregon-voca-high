# Oregon Voca High · 뉴오리건 고등 VOCA

예비고1부터 고3까지 학년별 핵심 영단어를 문맥과 함께 익히는 모바일 우선 웹앱입니다.

| 단계 | 단어 | 단원 | 퀴즈 |
|---|---:|---:|---:|
| 예비고1 | 200 | 10 | 단원당 10문항 |
| 고1 | 300 | 15 | 단원당 15문항 |
| 고2 | 300 | 15 | 단원당 15문항 |
| 고3 | 300 | 15 | 단원당 15문항 |

총 1,100개 학습 항목과 55개 단원입니다. 단원마다 20단어를 5개씩 나눈 카드 학습, 발음 듣기, 짝 맞추기, 철자, 문장 블록, 문맥 퀴즈를 제공합니다. 학생은 반·이름·4자리 PIN으로 입장하고, 선생님은 Supabase Auth 계정으로 반·학생·과제·음성 동의를 관리합니다.

## 콘텐츠 출처와 검수 상태

- 예비고1: 사용자가 제공한 「수능 대비 필수 영단어 200」 이미지 2장
- 고1·고2·고3: `모의고사_2024-2026_고1고2고3_각300_후보본.xlsx`
- 앱의 두 예문과 번역은 현재 문장 기능을 위한 초안입니다. 실제 수업 배포 전 영어교육 담당자의 자연스러움·난이도·의미 검수가 필요합니다.
- 동일 철자가 여러 학년에 있어도 학년·단원별 ID가 달라 진도가 섞이지 않습니다.

## 개발과 검증

Node.js 22 이상을 사용합니다.

```sh
npm ci
npm run seed:generate
npm test
npm run build
npm run dev
```

환경변수가 없으면 브라우저 로컬 체험 모드로 실행됩니다. Vercel Production 빌드는 Supabase 공개 설정이 없으면 중단하며, `service_role` 또는 `sb_secret_` 키가 `VITE_` 변수에 들어가도 중단합니다.

- `content/prep-high1.tsv`: 이미지에서 전사한 예비고1 200단어
- `scripts/import-high-school-curriculum.py`: 이미지 전사본과 학년별 Excel을 앱 데이터로 변환
- `src/data/high-school-source.js`: 생성된 1,100개 학습 항목
- `src/data/levels.js`: 4단계 정의, 진도, 퀴즈
- `src/db.js`: Supabase RPC 및 로컬 체험 모드
- `supabase/`: 공유 프로젝트에 추가하는 독립 `ovh` 스키마와 시드
- `docs/DEPLOYMENT.md`: GitHub → Supabase → Vercel 배포·검증 절차

## 보안과 운영

운영 데이터는 기존 Supabase 프로젝트 안의 `ovh` 스키마에 격리합니다. 학생 PIN은 bcrypt로 저장하고, 직접 테이블 권한은 거부하며 학생 토큰 또는 Supabase Auth 역할을 검증하는 RPC만 공개합니다. 결과 저장에는 요청 ID를 사용해 네트워크 재시도 시 포인트가 중복 지급되지 않게 합니다.

말하기는 보호자 동의를 선생님이 확인한 뒤 선택적으로 사용합니다. 브라우저 음성 인식은 발음 정확도 점수가 아니라 목표 표현과 인식 결과를 비교하는 보조 기능입니다.

자동 테스트는 콘텐츠 수, 학년별 분리, PostgreSQL 스키마·bcrypt·권한, 체크포인트, 중복 보상 방지, 화면 전환, 문맥 퀴즈, 문장 블록을 검증합니다.
